# 公众号选题与写作知识 Agent

工作名：`content-agent`。

用于长期积累文章、链接、图片和灵感，查询历史选题，发现值得延伸的角度，并在人工确认后创建和执行写作任务。

核心链路：身份与权限 → 必要信息补全 → 知识检索 → 业务记录查询 → 任务草稿 → 人工确认与执行 → 失败恢复 → 结果验收。

## 当前使用方式

当前仅有项目规范和阶段规划，尚无应用代码或启动命令。
