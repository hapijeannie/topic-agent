# 需求与边界

## 已确认目标

- 创建真正长期使用的公众号选题与写作知识 Agent，而非仅供面试的 Demo。
- 以 L 的企业级 RAG 与 S 的 Agent 执行、Python、行业落地要求为学习主线。
- 保持企业售后 Agent 的执行结构，只替换领域对象：手册对应文章资料，档案对应文章档案，工单对应写作任务。
- 每阶段讲概念并提供经核对的官方资料；每日记录实际进度；里程碑输出博客草稿。
- 在当前独立工作区建立项目，博客作为只读输入与未来发布载体。

## 业务链路

以下为长期目标链路。第一版收敛到「Markdown 入库 → 查历史与资料 → 一个选题建议 → 人工确认创建任务」，不自动撰写全文。

1. 确认账号和可访问知识范围。
2. 输入关键词或想法，必要时补问。
3. 检索历史文章，返回标题、链接或本地来源、相关段落与判断依据。
4. 查询文章发布状态、历史选题及未完成任务。
5. 若值得写且不存在重复任务，生成包含主题、角度、依据和交付要求的任务草稿。
6. 用户确认后创建任务，按指令执行资料收集、起草与审校。
7. 失败时保留状态，支持受控重试和恢复，防止重复业务写入。
8. 验收输出，记录执行步骤、结果、耗时和成本。

分支：已有文章满足需求时返回相关文章；已有任务时返回进度；主题相近但角度不同可建议延伸。没有检索到只能表述为「当前已收录内容中未找到」，不能声称从未写过。

## 素材与存储原则

- 输入包含 Markdown、公众号链接、图片、灵感。当前已有 Markdown 和部分公众号链接，后者尚未提供样本。
- 保留原始输入、解析正文、来源及版本；摘要和标签是派生信息，不替代全文。
- 图片保留原图，OCR 与模型描述分开记录；灵感保留原文，短内容不强制总结。
- 链接获取失败也保存输入和状态，允许重试或补充正文。
- 同文多来源需关联，内容改变需保留版本；相似度不是自动合并的充分依据。
- 区分自己文章、外部参考、草稿、已发布内容。资料、选题、任务是不同对象。
- 业务数据与正文拟用 PostgreSQL，文件拟用对象存储，向量索引拟用 pgvector；均尚未部署。

## 第一版五项功能与实现方案

以下为设计，尚未实施；数据库 schema 与迁移仍需单独确认。

| 功能 | 范围 | 实现机制 | JD 能力 |
|---|---|---|---|
| Markdown 入库 | 自己的文章和外部参考；保留原文、来源、归属；重复导入不重复建记录 | 网页选择一个或多个 .md 文件，服务端解析 Frontmatter 和正文，校验字段；原始文本及正文保存到 PostgreSQL；内容哈希识别变化，按标题和段落分块，Embedding API 生成向量，pgvector 存储分块向量；保存处理状态与版本 | 文档处理、RAG 索引、幂等 |
| 查历史与找资料 | 返回旧文、资料片段与引用，区分归属及发布状态 | 按账号和内容归属过滤，问题向量化后检索 Top K 分块，应用经过评测的相关性阈值，回查正文及来源；首版以向量检索为基线，混合检索与重排后续对照优化 | RAG、过滤、引用、评测 |
| 一个选题建议 | 标题、角度、旧文差异、证据、资料缺口 | 将检索结果与个人批注组织成上下文，模型输出结构化字段，程序校验字段和引用 ID；不足时明确报告，不把候选说成成熟选题 | Prompt、结构化输出、业务判断 |
| 确认创建任务 | 确认／拒绝，恢复待确认状态，避免重复创建 | 查询历史任务的工具，LangGraph 保存运行状态并等待人工确认；数据库持久化与幂等键保护任务写入；确认后任务进入待写状态，不执行全文写作 | 工具调用、人工确认、状态恢复、幂等 |
| 可访问与可验证 | 单个工作台、简单历史任务列表、个人账号访问控制 | Next.js 前端、Python 服务、基础鉴权、Docker 部署方案；结构化日志关联运行 ID，记录耗时／Token／成本，固定案例集验证质量与异常行为 | 全栈交付、运行维护、可观测性 |

Markdown 首版不要求先用 AI 重做每篇摘要：已有 description 原样保留，无摘要不阻塞正文索引。fuxi 已有批注、立场、角度应保留并注明来源；自动批量生成理解层后续增加。自有文章同样建立正文分块索引，不能只索引外部素材。

原文和索引分开保存。来源标识决定记录身份，哈希辅助判断内容变化，不能单独代替身份或语义去重。变更后建立新索引版本，成功才切换有效版本，失败保留原文及错误状态；不能把未完成的索引报告为可检索。超长代码块等边界需在实现时明确模型输入预算与拆分策略。

## 延后但明确必做

- 长期记忆：跨会话偏好与知识的更新、归属、删除及效果验证。
- 多 Agent：基于单 Agent 基线实现协作，并评估收益、成本和失败路径。
- MCP 接口：对外提供受控的知识与任务工具。
- 独立 Skill 包：选题、写作、审校方法及其适用边界。
- 多租户和复杂权限：租户／知识空间隔离、角色与资源授权、检索和工具权限测试。

以上不是可选项，第一版暂不实现；第一版仍需个人账号鉴权和数据归属。

## 其他延期功能

- 对素材自动生成摘要、原文主张、候选角度和关系，保留用户批注。
